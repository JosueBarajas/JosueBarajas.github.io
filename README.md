# College portfolio
A static website using plain HTML, CSS and JavaScript. No installation, dependencies or build step.

## Run locally
1. Extract the ZIP into a folder.
2. Open the folder in VS Code (optional) or any text editor.
3. Open index.html in your browser. Refresh after saving edits.

## Customize
- index.html: replace every bracketed placeholder, page title, and YN initials. Remove unused sample cards. Keep claims accurate.
- style.css: edit the colors in :root, spacing and typography.
- script.js: mobile menu, project filters and automatic footer year.
- To add a project, duplicate an article with class="project" and set its data-category to research or creative (or add a matching filter).
- To add project links, use an anchor with a real URL and descriptive link text. Only link public work you have permission to share.

## Publish using GitHub Pages
If eligible under the service terms, create a repository (e.g. username.github.io), upload index.html, style.css and script.js to the repository root, then open Settings > Pages. Choose Deploy from a branch, main, / (root), and save. GitHub will display the published address after deployment. A parent or guardian can help with account setup and privacy review.

Before making it public, remove private details: home address, birth date, personal phone, school schedule, student ID, and sensitive documents. Consider using initials or a first name, and omit school name if it identifies your location. Review any photos and document metadata. No contact form, analytics, or personal data collection is included. The website is a template, not a verified record of your accomplishments.

## Checks
Preview at narrow and wide browser sizes, test the navigation and project filters, verify all links, and review spelling. The site works without JavaScript except for enhanced menu and filtering; the navigation and all projects remain visible.
